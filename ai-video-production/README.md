# Freelance — рабочая зона AI Edit Studio

Эта папка предназначена для всех последующих заказных монтажных проектов.

## Самый простой способ начать новый проект

1. В `00_INBOX` создайте папку с названием проекта, например `Client_Project_Name`.
2. Можно просто положить внутрь все материалы без сортировки.
3. Напишите в Codex название проекта и задачу по монтажу.
4. Codex проверит материалы, создаст рабочую структуру по `_PROJECT_TEMPLATE` и перенесёт проект в `01_ACTIVE_PROJECTS` после вашего разрешения.

Если удобнее сразу раскладывать материалы, скопируйте `_PROJECT_TEMPLATE`, переименуйте копию и используйте:

- `01_RAW_VIDEO` — исходное видео;
- `02_VOICE` — озвучка, дикторская речь и отдельные аудиозаписи;
- `03_MUSIC` — музыка, которую нужно рассмотреть для монтажа;
- `04_ASSETS` — фотографии, логотипы, графика, шрифты и дополнительные медиа;
- `05_REFERENCES` — примеры монтажа, ссылки, скриншоты и пожелания;
- `00_BRIEF` — описание задачи.

Папки `06_PROJECT_FILES`, `07_PREVIEW` и `08_EXPORT` заполняет AI Edit Studio.

## Статусы

- `00_INBOX` — новые материалы, которые ещё не разобраны;
- `01_ACTIVE_PROJECTS` — проекты в работе;
- `02_CLIENT_REVIEW` — версии, отправленные на согласование;
- `03_DELIVERED` — завершённые и выданные проекты;
- `04_ARCHIVE` — архив закрытых проектов;
- `_PROJECT_TEMPLATE` — эталонная структура нового проекта.

## Важные правила

- Исходники не редактируются, не переименовываются и не удаляются без разрешения.
- Перед монтажом проверяются все предоставленные папки и файлы.
- Если в `03_MUSIC` есть музыка, она обязательно прослушивается и учитывается.
- Автоматическая расшифровка используется только для поиска сцен, но не для финальных границ реплик.
- Перед выдачей ролик полностью просматривается и прослушивается в реальном времени.
