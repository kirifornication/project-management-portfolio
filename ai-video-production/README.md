# Структура проекта

- `00_BRIEF` — бриф и текстовые инструкции;
- `01_RAW_VIDEO` — оригинальные видеофайлы;
- `02_VOICE` — озвучка и отдельные аудиозаписи;
- `03_MUSIC` — музыкальные треки;
- `04_ASSETS` — графика, фото, логотипы и шрифты;
- `05_REFERENCES` — примеры и референсы;
- `06_PROJECT_FILES` — Remotion-проект, расшифровка, прокси и анализ;
- `07_PREVIEW` — черновые версии для проверки;
- `08_EXPORT` — финальные файлы;
- `09_ARCHIVE` — устаревшие версии после подтверждения пользователя.

Пользовательские исходники в папках `01`–`05` не изменяются.
