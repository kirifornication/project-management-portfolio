# Локальный транскрибатор видео и аудио

Программа извлекает звук из локального файла, распознаёт речь с помощью
`faster-whisper` и сохраняет обычный текст, аккуратно очищенный текст, JSON и
субтитры. Исходный файл не меняется и никуда не отправляется. Интернет нужен
только при первом скачивании выбранной модели Whisper.

## Быстрый старт

1. Установите Python 3.11 или новее и ffmpeg.
2. Откройте терминал в папке проекта.
3. Создайте окружение: `python -m venv .venv`.
4. Активируйте его:
   - Windows: `.venv\Scripts\activate`
   - macOS/Linux: `source .venv/bin/activate`
5. Установите зависимости: `python -m pip install -r requirements.txt`.
6. Положите видео или аудио в папку `input`.
7. Запустите `run_transcription.bat` (Windows), `./run_transcription.sh`
   (macOS/Linux) или `python transcribe.py input`.
8. Откройте `output/<название>/clean_transcript.txt`.

## Поддерживаемые файлы

Видео: `.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`, `.m4v`.

Аудио: `.mp3`, `.m4a`, `.wav`, `.aac`, `.flac`, `.ogg`, `.opus`.

Пути с пробелами, кириллицей, вьетнамскими и другими Unicode-символами
поддерживаются.

## Что требуется

- Windows 10/11, macOS или Linux;
- Python 3.11+;
- `ffmpeg` и `ffprobe`, доступные из терминала;
- минимум несколько гигабайт свободного места;
- интернет при первом запуске новой модели.

Для длинных файлов желательно 8–16 ГБ оперативной памяти. NVIDIA GPU ускоряет
работу, но не обязателен.

## Установка ffmpeg

### Windows

Удобный вариант через WinGet:

```powershell
winget install --id Gyan.FFmpeg
```

Закройте и заново откройте терминал, затем проверьте:

```powershell
ffmpeg -version
ffprobe -version
```

### macOS

```bash
brew install ffmpeg
```

### Ubuntu/Debian

```bash
sudo apt update
sudo apt install ffmpeg
```

## Запуск

Один файл:

```powershell
python transcribe.py "input/Составить маршрут путешествия за 20 мин в любой стране — ЛЕГКО.mp4"
```

Все поддерживаемые файлы из папки:

```powershell
python transcribe.py input
```

Пакет обрабатывается по очереди. Ошибка одного файла не останавливает остальные.
Успешно готовые файлы при повторном запуске пропускаются.

Полезные параметры:

```text
--language ru          распознавать русскую речь
--language auto        определить язык автоматически
--model small          быстрее и экономнее
--model medium         рекомендуемый баланс по умолчанию
--model large-v3       точнее, но требует больше ресурсов
--device cpu           только процессор
--device cuda          только NVIDIA GPU
--device auto          GPU при реальной доступности, иначе CPU
--compute-type int8    экономный режим CPU
--overwrite            пересоздать готовый результат
--keep-temp            сохранить подготовленный WAV
--log-level DEBUG      подробный журнал
--output-dir ПАПКА     другая папка результатов
```

Пример:

```powershell
python transcribe.py "input/video.mp4" --language ru --model medium --device auto
```

При `--device auto` программа проверяет CUDA. Если GPU нет, используется CPU
`int8`. При нехватке памяти NVIDIA во время работы выполняется одна повторная
попытка на CPU. Для принудительного GPU используйте `--device cuda`; если CUDA
недоступна, программа выдаст понятную ошибку.

## Настройки YAML

Скопируйте `config.example.yaml` в `config.yaml`, измените нужные значения и
запускайте так:

```powershell
python transcribe.py input --config config.yaml
```

Параметры командной строки имеют приоритет над YAML, а YAML — над встроенными
значениями.

## Результаты

Для каждого исходника создаётся отдельная читаемая папка:

```text
output/
└── название видео/
    ├── raw_transcript.txt
    ├── clean_transcript.txt
    ├── transcript.json
    ├── subtitles.srt
    ├── subtitles.vtt
    └── metadata.json
```

- `clean_transcript.txt` — главный результат с консервативной локальной очисткой;
- `raw_transcript.txt` — полный текст без временных меток;
- `transcript.json` — текст и сегменты с временными метками;
- `subtitles.srt` и `subtitles.vtt` — субтитры;
- `metadata.json` — исходные параметры, версии, язык, время и статус.

Если два исходника имеют одинаковое имя, ко второму имени добавляется короткий
стабильный хеш. Результат сначала полностью пишется во временную папку и только
после успеха заменяет финальную папку, поэтому смесь старых и новых файлов не
остаётся.

## Повторная обработка

Обычный повторный запуск пропускает папку с успешным `metadata.json`. Чтобы
пересоздать все файлы:

```powershell
python transcribe.py "input/video.mp4" --overwrite
```

## Возможные ошибки

- **ffmpeg/ffprobe не найден** — установите ffmpeg и перезапустите терминал.
- **нет аудиодорожки** — файл содержит только видео.
- **модель не скачалась** — проверьте интернет и свободное место.
- **CUDA недоступна** — используйте `--device cpu` или настройте NVIDIA-драйвер.
- **не хватает памяти** — выберите `small`, `--device cpu` и закройте тяжёлые программы.
- **нет прав на запись** — перенесите проект в доступную пользователю папку.
- **файл повреждён** — проверьте воспроизведение и диагностическое сообщение ffprobe.

Нажатие `Ctrl+C` не помечает незавершённую работу как успешную. Временный WAV
удаляется, если не указан `--keep-temp`.

## Тесты

Обычные тесты используют имитацию транскрибатора и не скачивают Whisper:

```powershell
pytest
```

## Известные ограничения

- говорящие не разделяются;
- перевод и смысловое редактирование не выполняются;
- пунктуация зависит от Whisper;
- модель `large-v3` может быть слишком тяжёлой для обычного компьютера;
- первая загрузка модели может занять заметное время;
- точность снижается при шуме, музыке и наложении голосов.

Логичные будущие улучшения: выбор аудиодорожки, разметка говорящих, пользовательский
словарь имён и дополнительный необязательный редактор текста.
